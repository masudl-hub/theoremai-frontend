## Docs

Before drafting, editing or reviewing any public docs page, draft (`tmp/docs-scratch/`), chapter (`app/lib/docs/articles/`) or snippet, read [`docs/DOCS_CONTRACT.md`](docs/DOCS_CONTRACT.md) in full and write to it.

**Clear is kind, and only the package's truth is clear.** If the package cannot answer something a page needs, stop and ask. Do not fill the gap.

The contract changes only in that file, and only when the maintainer agrees the change.
